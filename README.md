# 2048 Noir

A dark-themed 2048 puzzle game for Android.

> 🧪 Currently in testing on Google Play. The link will be added after release.

> 📚 **Note:** This project was created while I was learning Android development. The code is not perfect and may contain mistakes or messy parts. I'm improving it as I learn.

## How to play
- Swipe to move all tiles in one direction.
- When two tiles with the same number touch, they merge into one.
- Reach the 2048 tile to win.

## Features
- Swipe controls
- Undo your last move
- Score tracking and top 3 records
- Sound effects with music on/off button
- Share button
- Restart confirmation dialog

## Tech
- Language: Kotlin
- Platform: Android (min SDK 24)
- IDE: Android Studio
